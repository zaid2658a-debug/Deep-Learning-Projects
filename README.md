# AI / Machine Learning Tasks

This repository contains coursework and practical machine-learning tasks, organized by task number.

## Project Structure

```text
.
├── task1/
│   ├── Bengaluru_House_Price/
│   ├── Churn_Modelling/
│   └── README.md
│
└── task2_Cnn/
    ├── 0.0 FashionMNIST_Cnn/
    ├── 0.1 SVHN_Cnn/
    ├── 1.0 CNN_DataGen_From_RAM_clothing-image/
    └── README.md
```

## Task 1

The `task1` folder contains the first set of machine-learning tasks:

- **Bengaluru House Price**
- **Churn Modelling**

A dedicated README is included inside the `task1` folder.

## Task 2 - CNN

The `task2_Cnn` folder contains CNN-based image-classification work with multiple datasets and experiments:

- **Fashion-MNIST CNN**
- **SVHN CNN**
- **CNN Data Generator / Clothing Image experiment**

A dedicated README is included inside the `task2_Cnn` folder.

## Notes

Each task folder is kept independent so that the notebooks, models, and documentation for each task remain organized and easy to review.

## Tools

The projects are primarily developed using:

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- scikit-learn
- Google Colab

## Repository Organization

The recommended structure is to keep:

- one README at the repository root for an overall project overview;
- one README inside each major task folder for task-specific details.
